# 🔊 הקראה – תוסף לכרום ולאדג'

מסמנים טקסט בכל אתר, לוחצים – והוא מוקרא בעברית בקול אנושי וטבעי (הקול של Google Gemini).

## מה הוא עושה

- **טקסט מסומן:** מסמנים טקסט ← לחיצה ימנית ← "🔊 הקרא בקול" (או לחיצה על כפתור התוסף, או `Alt+Shift+K`).
- **דף שלם:** לחיצה ימנית על הדף ← "🔊 הקרא את כל הדף".
- **הדבקה:** אפשר גם להדביק מאמר ישירות בחלונית.
- ההקראה נפתחת בחלונית צד, עם השהיה, דילוג בין קטעים, בחירת קול (2 נשים, 2 גברים) ומהירות.
- טקסט שהועתק מצ'אט (כותרות, כוכביות, אימוג'י, קישורים) מנוקה אוטומטית לפני ההקראה.

## התקנה

1. מורידים את `hakraa-extension.zip` מעמוד ה-[Releases](../../releases/latest) ומחלצים לתיקייה קבועה.
2. פותחים בכרום `chrome://extensions` (באדג': `edge://extensions`).
3. מדליקים **מצב מפתח** (Developer mode).
4. לוחצים **טען פריט שנפרק** (Load unpacked) ובוחרים את התיקייה שחולצה.

## מפתח גוגל (חינם)

הקול הטבעי מגיע מ-Google Gemini, ולכן צריך מפתח אישי – חינמי:

1. נכנסים ל-[Google AI Studio](https://aistudio.google.com/apikey) ויוצרים מפתח.
2. בחלונית של התוסף לוחצים **⚙ מפתח גוגל**, מדביקים ושומרים.

בלי מפתח התוסף עובד עם קול המחשב (באדג' – הקולות הטבעיים של מיקרוסופט).

## פרטיות

- הטקסט שמבקשים להקריא נשלח ל-Google (Gemini API) כדי להפוך אותו לקול. הוא לא נשלח לשום מקום אחר.
- המפתח נשמר רק בדפדפן שלך.
- התוסף קורא טקסט מדף רק ברגע שלוחצים על אחד מכפתורי ההקראה.

# איך מקבלים מפתח גוגל (חינם, שתי דקות)

הקול הטבעי של "הקראה" מגיע מ-Google Gemini. כדי להשתמש בו צריך מפתח אישי – חינמי, בלי כרטיס אשראי.

1. נכנסים ל-[Google AI Studio](https://aistudio.google.com/apikey) ומתחברים עם חשבון Google.
2. לוחצים **Create API key** (יצירת מפתח). אם מתבקשים – מאשרים את תנאי השימוש.
3. לוחצים על סמל ההעתקה שליד המפתח החדש.
4. חוזרים לחלונית של התוסף, לוחצים **⚙ מפתח גוגל**, מדביקים ולוחצים **שמור**.

זהו. מעכשיו ההקראה בקול הטבעי.

## טוב לדעת

- המפתח נשמר רק בדפדפן שלך. לא משתפים אותו עם אחרים.
- במסלול החינמי יש מכסת שימוש יומית. כשהיא נגמרת התוסף עובר לבד לקול המחשב, וחוזר לקול גוגל כשהמכסה מתחדשת.
- בלי מפתח התוסף עובד עם קול המחשב.
- [מדיניות הפרטיות של התוסף](privacy.md)
